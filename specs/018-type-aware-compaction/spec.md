## Prior-Art Decision

Actual arXiv abstracts were fetched on 2026-08-27 and read in isolated lanes.
The selected path is deterministic Knowledge Triage, not learned online memory:

- [Compaction Cliff, arXiv:2608.22752](https://arxiv.org/abs/2608.22752) reports
  severe repeated-compaction rule loss and motivates per-type deterministic
  retention.
- [HERO, arXiv:2608.22310](https://arxiv.org/abs/2608.22310) motivates retaining
  raw evidence instead of treating rewritten summaries as evidence.
- [InjecMEM, arXiv:2608.23471](https://arxiv.org/abs/2608.23471) makes retrieved
  commands a required poisoning threat model.
- [AdmitOR, arXiv:2608.15565](https://arxiv.org/abs/2608.15565) shows execution
  success is an unsafe memory-admission rule and reports failed wild-stream
  transfer of a calibrated threshold.

Therefore this slice uses explicit, deterministic user markers and does not add
a learned classifier, online admission, or generated-memory authority.

## Requirements

### Requirement 1 - Conservative explicit classification (Priority: P1)

**Acceptance**:
1. Inspect user-role text only.
2. Admit lines beginning with exact uppercase English markers (`RULE:`, `INVARIANT:`,
   `CONSTRAINT:`, `REQUIREMENT:`, `MUST`, `NEVER`, `ALWAYS`) or Korean markers
   (`규칙:`, `불변식:`, `제약:`, `요구사항:`, `반드시`, `절대`).
3. Ordinary text, assistant/tool text, and user messages containing `<file>` or `<stdin>` attachment data remain episodic.
4. Reject lines containing managed markers, control/line-separator characters, or exceeding 1,000 chars.
5. Force credential redaction before both summary rendering and detail persistence.

### Requirement 2 - Deterministic managed block (Priority: P1)

**Acceptance**:
1. Inject one `Preserved Rules & Invariants (verbatim)` block after LLM output.
2. Strip any case-varied managed header, start/end marker, or source marker generated by the model before injection.
3. Deduplicate exact strings in stable source order.
4. Preserve at most 64 rules.

### Requirement 3 - Repeated-compaction survival (Priority: P1)

**Acceptance**:
1. Persist canonical records containing redacted text, source user-entry ID,
   source line, and digest in additive default-compaction details.
2. Read prior rules only from strictly validated non-hook details whose rendered
   canonical block is present in the prior summary.
3. Preserve the managed block byte-identically for at least five rounds.
4. Include split-turn prefix user rules before discarded messages are removed.

### Requirement 4 - Scope boundary (Priority: P2)

**Acceptance**:
1. Default history compaction is covered.
2. Custom hook summaries remain caller-owned and are not promoted to trusted rules.
3. Branch-summary and cross-session memory expansion require separate specs.
4. Existing file-operation tracking remains unchanged.

## Non-Goals

- Claiming arbitrary natural-language rule classification
- Treating assistant, tool, retrieved memory, or generated summaries as authority
- Cross-session memory storage or retrieval
- Learned compaction, embedding search, or online policy promotion
- Replacing raw source evidence with summary text

## Assumptions

- Explicit markers trade recall for precision.
- Source and test evidence remain authoritative over summaries.
- This worktree implementation is unreleased.
